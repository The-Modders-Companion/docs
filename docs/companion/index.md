**The Modder's Companion** is a semi-modular handbook for modding Skyrim. Unlike conventional guides, the *Companion* does not instruct you to install a pre-determined set of mods but helps you make your own choices and build a custom setup from scratch.

The *Companion* is ^^not^^ a guide to creating mods.

## The Primer

Before we proceed, **I strongly recommend you read my Primer on modding Skyrim**. The Primer explains important terminology and outlines different approaches to acquiring a custom setup. By the end of the article, you will be able to make an informed choice on how to proceed – with the *Companion* or elsewhere.

## The Companion

Still here and interested in using the *Companion*? Fantastic! Keep reading for some final notes and clarifications before we properly jump into the guide.

### Target Audience

The Modder's Companion is geared towards new and experienced modders who are interested in building a stable, consistent, and performant setup. No prior knowledge is required.

The framework that structures the *Companion* is my own. I do not claim to have devised the best possible approach to modding Skyrim, and certainly mine is not the only one. ==My approach will appeal to you if you are interested in a structured process and you value understanding why steps are taken.== Only by grasping the fundamentals will you be able to make your own informed decisions – and avoid the headache of seemingly 'inexplicable' problems hounding you at every step.

### Structure

As the guide is a work in progress (see the next section for details), so is the structure.

- :green_circle: **Foundation:** This section focuses on the initial setup and creation of a solid workbase to build on afterwards. The *Foundation* is the most linear part and should come in handy for anyone looking to build a new setup from scratch.
- :construction: **Modding Basics:** This section provides an interactive introduction to basic modding knowledge, using the workbase created previously. Following this section is optional but highly recommended.
- :construction: **The Sandbox:** This section provides guidance on the real meat of the setup - selecting, testing, and modifying mods. My instructions and recommendations here are geared specifically towards building large, complex setups.

## Questions & Answers

**I'm more interested in making mods than building a setup. Where do I begin?**

Actually, the *Companion* is a pretty good starting point for that, too! I'd recommend following at least the *Foundation* to get a proper workbase set up with all the most important tools. This is very useful for mod creation – plus the section contains a lot of basic modding knowledge that more advance mod creation tutorials often do not cover.
