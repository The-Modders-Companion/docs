## MO2 Profiles

Among MO2's many powerful features is the ability to create an indefinite amount of self-contained profiles.

Every profile has its own:

- Load order
- Mod order
- Save Files (optional)
- INI Files (optional)

This means that the same mods are installed across all profiles but you can choose which mods are enabled per profile. As a result, you can set up one profile that's just vanilla, a second with a few mods for testing, and a third for a particular playthrough – all in the same MO2 instance.

### Creating a New Profile

- Open the MO2 profiles settings by clicking the ID card icon in the **Toolbar**.

![MO2 Profiles Setting](/companion/foundation/assets/mo2-profiles-settings.png)

Click the Create button and enter The Phoenix Flavour as the new name.
Make sure that Default Game INI Settings is checked.
Click OK to create your new profile.
Click on your new profile in the list and check both Use profile-specific Save Games and Use profile-specific Game INI Files.
Click Select to quickly switch to your new profile.
